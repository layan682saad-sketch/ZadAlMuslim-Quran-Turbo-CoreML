# Quran Turbo for WhisperKit

CoreML INT8 conversion of `naazimsnh02/whisper-large-v3-turbo-ar-quran`, source revision `670f826cf3731ae9f6b3f54d4a417d8f600e2cd2`.

Only compiled model assets and provenance are hosted here. Application source and signing material are not included.

The source model is published under Apache-2.0. Preserve its attribution and license. The source model card accompanies the release. Conversion uses Argmax WhisperKit Tools, with component parity checks; this does not certify Quran recitation, tajwid, or user error detection.

Download `quran-model.json` from the tagged release for exact file names, sizes and SHA-256 values. Model weights are downloaded on demand; they are not part of the application bundle.
